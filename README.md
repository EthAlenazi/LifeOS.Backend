# LifeOS.Backend

## Project Overview

LifeOS.Backend is a personal life management backend API designed to help organize and track different areas of daily life from one system.

## Goal

The goal of this project is to build a real-world backend system that can manage personal goals, routines, tasks, progress, and daily activities while applying professional backend development practices.

## Main Features

* Goal tracking
* Daily routines management
* Task management
* Progress tracking
* Daily activity logging
* Personal dashboard data
* User authentication and authorization

## Tech Stack

* ASP.NET Core
* C#
* Entity Framework Core
* SQL Server
* REST APIs
* JWT Authentication

## Planned Technical Additions

* Docker for containerizing the application after the MVP is working locally
* Azure for final cloud deployment and hosting
